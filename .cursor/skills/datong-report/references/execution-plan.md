# 执行计划模板

> 收到埋点需求后，先展示计划再执行。本文档定义计划模板和裁剪规则。

---

## 标准计划模板（用户已有埋点信息 / 选择 A 路径）

```markdown
## 📋 埋点接入计划

### Step 1：识别技术栈 & 确定 SDK
- 扫描项目结构，判断技术栈（H5 / Android / iOS / 其他）
- 检测项目已引入的大同 SDK，加载对应文档

### Step 2：获取埋点信息
- 通过 **埋点信息码 / appId + pageId** 获取事件详情

### Step 3：生成上报代码
- 按优先级生成符合项目风格的代码

### Step 4：联调验证（可选）
- 开启实时联调，验证埋点数据

---
> 确认后开始执行。已有埋点信息码/appkey 可直接提供。
```

---

## 从零开始计划模板（用户选择 B 路径）

> 当用户没有埋点信息、希望从零开始时使用本模板。核心思想：**指标驱动埋点**，先对齐业务目标，再落地埋点。

```markdown
## 📋 埋点接入计划（从零开始）

### Step 1：识别技术栈 & 确定 SDK
- 扫描项目结构，判断技术栈
- 检测/选定大同 SDK

### Step 1.2：注册大同应用 🔑
- 自动注册大同应用，获取 appkey
- 将 appkey 配置到 SDK 初始化代码中

### Step 2：场景识别 & 指标推荐 🎯
- 分析项目代码，识别业务场景（电商、SaaS、内容社区等）
- 基于场景库推荐核心业务指标（North Star + 核心结果 + 诊断指标）
- **与你确认指标清单**，再进入埋点设计

### Step 3：由指标反推埋点方案
- 为每个指标映射所需事件
- 在项目代码中定位事件触发位置
- 产出按页面组织的埋点方案文档

### Step 4：生成上报代码
- 基于埋点方案，生成符合项目风格的代码

### Step 5：整理表格式埋点清单 & 上传平台
- 输出标准表格格式的埋点事件文档
- 自动上传到大同平台

### Step 6：看板 Prompt 生成（可选）
- 询问是否生成看板 Prompt，用于「智能看数」一键创建数据看板

### Step 7：联调验证（可选）
- 开启实时联调，验证埋点数据

---
> 确认后开始执行。如不想走指标推荐，可以说"直接扫代码出埋点"跳过 Step 2。
```

---

## 计划裁剪规则

根据用户已提供的信息，动态调整计划中各步骤的状态标注：

| 条件 | 标注 |
|------|------|
| 用户已提供 `Datong_XXXX` | 对应步骤标注 "✅ 已有" |
| 用户指定了 SDK | Step 1 标注 "✅ 已确认" |
| 用户未提及联调 | 联调步骤标注 "⏭️ 暂跳过" |
| 用户明确拒绝指标推荐 | 从零计划的 Step 2 标注 "⏭️ 跳过" |
| 用户已明确业务场景/指标 | 从零计划的 Step 2 标注 "✅ 已明确" |
