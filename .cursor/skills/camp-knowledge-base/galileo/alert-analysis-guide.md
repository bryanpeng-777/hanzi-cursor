## AutoLogin QQ鉴权失败版本集中告警

- **告警类型**：量级超阈值 + 错误率实质恶化
- **涉及 moduleName**：`AutoLogin`（campType: end）
- **规律描述**：App 版本升级后，新版本 QQ 自动登录的 token 参数（payToken/pfKey/accessToken）与服务端鉴权不匹配，导致 `/user/login` 返回 `-50000: QQ鉴权失败`，用户被迫手动登录。错误高度版本集中（新版本占 80%+）。
- **分析套路**：
  1. 先查 errorCode 分布（本类错误主要是 `-50000`、`-30003` 并存）
  2. 查 `-50000` 的版本分布 → 确认是否版本集中
  3. 取 Trace 查 `/user/login` span 的 `errorMsg` → 确认是 "QQ鉴权失败" 还是其他原因
  4. 若版本集中 + "QQ鉴权失败" → 排查新版本 QQ SDK 升级 / token 传参逻辑变更
- **判断依据**：`errorCode=-50000` + `errorMsg="QQ鉴权失败"` + 新版本占比 80%+；`newUserId` 为空说明自动登录未成功
- **处置建议**：建议修复 — 检查新版本 QQ 登录 token 生成/传参逻辑，确认 QQ SDK 与服务端鉴权接口兼容性
- **首次记录**：2026-04-27
- **最后更新**：2026-04-27
