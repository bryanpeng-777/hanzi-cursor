# The Daily Print — 排版规范与内容约定

本文档是 The Daily Print 日报生成的快速参考手册，涵盖页面结构、CSS 类速查、板块选用指南和内容格式约定。

---

## 一、页面结构总览

```
newspaper
├── masthead（报头）
│   ├── masthead-top: EST. {年} | 第 N 期 | 星期X
│   ├── h1: {报纸名}
│   └── masthead-motto: {用户自定义 motto}
├── date-bar（日期栏）
│   ├── 日期 + 农历
│   ├── 每日名言（英文）
│   └── weather-badge: DAILY BRIEFING
├── 板块1（根据订阅源动态选择模板 A/B/C）
├── pull-quote（每日引言，放在第 1 和第 2 板块之间）
├── ornament（装饰分隔符，板块之间）
├── 板块2
├── ornament
├── 板块3 ...（按需）
└── footer
    ├── 报纸名 + 日期
    ├── 数据来源列表
    └── 版权声明
```

## 二、三种板块模板

根据订阅源类型选用不同的板块模板：

### 模板 A：主板块（headline + columns-3）

**适用场景：** 新闻、科技、财经等资讯类，内容 ≥ 7 条

**结构：**
- 1 条头条（`.headline-story`，双栏摘要）
- 三栏副条（`.columns-3`），每栏最多 3 篇（1 篇 `.article-lg` + 2 篇 `.article`）

**建议：** 每期日报最多 1 个主板块（内容最丰富的分类）。

### 模板 B：列表板块（list-section）

**适用场景：** 社区/论坛类（如 V2EX、Hacker News、Reddit），或简讯汇总

**结构：**
- 两栏列表（`.list-section`），每条 `[标签] + 标题链接`
- 通常 8-12 条

**CSS 类：**
- `.list-item`：单条（flex + baseline 对齐）
- `.list-tag`：标签（深底浅字小标签）

### 模板 C：主区域 + 侧边栏（grid-with-sidebar）

**适用场景：** 体育（比分面板）、深度资讯（数据面板 + 短讯）

**结构：**
- 左侧：1 条板块头条 + 两栏副条（`.columns-2`，每栏最多 3 篇）
- 右侧侧边栏（`.sidebar`）：数据框（`.stat-box`）+ 短讯（`.sidebar-item`）

**⚠️ 视觉平衡规则：** 副条两栏的文章数量不是固定的，需要根据侧边栏的实际内容高度来动态调整。生成时应先估算侧边栏高度（数据框 + 短讯条数），然后让左侧主区域的总高度与之大致匹配：
- 侧边栏内容较多（数据框 + 3 条以上短讯）：副条每栏可放 3 篇，避免右侧溢出左侧留白
- 侧边栏内容适中（数据框 + 1-2 条短讯）：副条每栏 2 篇即可
- 侧边栏内容较少（仅数据框，无短讯）：副条每栏 1-2 篇，或考虑换用模板 A
- **核心原则：左右两侧底部应大致齐平，不允许出现大面积空白。** 如果素材不够填满，优先减少侧边栏内容或切换模板，而非留空。

**选用依据：**

| RSS 源类型 | 推荐模板 |
|-----------|---------|
| 新闻 / 科技 / 财经（文章量大） | 模板 A |
| 论坛 / 社区 / 热榜 | 模板 B |
| 体育（含比分数据） | 模板 C |
| 知识 / 公众号精选 | 模板 A 或 B |
| 编程 / 技术博客 | 模板 B |
| ≤ 5 条内容的小板块 | 模板 B（单栏） 或 `.columns-2` |

## 三、CSS 类速查

### 板块容器

| 类名 | 用途 | 布局方式 |
|------|------|---------|
| `.columns-3` | 三栏文章 | CSS Grid 3 等分 |
| `.columns-2` | 两栏文章 | CSS Grid 2 等分 |
| `.grid-with-sidebar` | 主区域 + 侧边栏 | Grid `2fr 1fr` |
| `.list-section` | 列表式内容 | CSS Multi-column 2 栏 |
| `.scoreboard-grid` | 比分/数据两列 | Grid 2 等分 |

### 文章卡片

| 类名 | 说明 |
|------|------|
| `.article` | 标准文章卡片 |
| `.article-lg` | 加大文章（标题 1.35rem，摘要 0.92rem） |
| `.headline-story` | 头条（标题 2.4rem，双栏摘要） |
| `.sidebar-item` | 侧边栏短讯（仅标题 + 短摘要） |

### 列表

| 类名 | 说明 |
|------|------|
| `.list-item` | 单条列表项（flex + baseline 对齐） |
| `.list-tag` | 标签（深底浅字小标签） |

### 数据面板

| 类名 | 说明 |
|------|------|
| `.stat-box` | 数据框（浅灰背景 + 边框） |
| `.stat-row` | 单行数据（flex 两端对齐） |
| `.stat-name` | 名称（粗体） |
| `.stat-value` | 数据值 |
| `.scoreboard-match` | 单条比分（flex 居中） |
| `.wt` / `.ws` / `.sc` / `.ls` / `.lt` | 赢方名/赢方分/冒号/负方分/负方名 |
| `.ot-tag` | 附加标记（红底白字小标签） |

### 装饰元素

| 类名 | 说明 |
|------|------|
| `.section-header` | 板块标题（左右横线 + 居中文字） |
| `.ornament` | 装饰分隔符 `◆ ◆ ◆` |
| `.pull-quote` | 引言（左边框 + 斜体） |

## 四、内容格式约定

### 1. 标题

- **头条标题：** 20-40 字，突出核心新闻要素
- **副条标题：** 15-30 字，简洁有力
- **列表标题：** 不超过 30 字
- **侧边栏标题：** 15-25 字
- 中文日报全部使用中文（URL 除外）
- 英文日报保持原文

### 2. 摘要

- **头条摘要：** 100-200 字，提供充足背景
- **副条摘要：** 60-120 字，一两句话
- **侧边栏摘要：** 30-60 字，一句话

### 3. 来源标注

格式：`来源网站 · 分类标签`

示例：
- `IT之家 · 芯片`
- `36氪 · AI`
- `BBC · World`
- `TechCrunch · Startup`

### 4. 比分/数据面板

**比分格式（体育类）：**

```html
<div class="scoreboard-match">
  <span class="wt">赢方</span>
  <span class="ws">赢方比分</span>
  <span class="sc">:</span>
  <span class="ls">负方比分</span>
  <span class="lt">负方</span>
</div>
```

规则：赢方在左（加粗 800），负方在右（正常 400）。

**通用数据格式：**

```html
<div class="stat-row">
  <span class="stat-name">名称</span>
  <span class="stat-value">数据</span>
</div>
```

附加信息用方括号 `[]`，如 `[三双]`、`[新高]`。
**禁止使用中文圆括号** `（）`，一律用方括号 `[]`。

### 5. 每日名言

放在 `.date-bar .quote` 中，格式：
```
"英文名言内容" — 作者名
```

控制在 15 个英文单词以内。

### 6. 每日引言（Pull Quote）

放在 `.pull-quote` 中，从当日新闻中提炼一句有冲击力或启发性的观点。加引号。

## 六、文件命名

```
{file_prefix}-YYYYMMDD.html
```

`file_prefix` 从 `user-config/profile.json` 读取。

示例：`zach-daily-newspaper-20260401.html`

保存路径从 `profile.json` 的 `output_dir` 字段读取。
