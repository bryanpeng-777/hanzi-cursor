# 🗞️ The Daily Print

> *你还记得那份报纸的味道吗？*

清晨的阳光透过窗帘，父亲翻开一份刚送到的日报，油墨的气息混着早餐的香味弥漫在空气里。头条、社论、体育版、副刊——每个板块都是一扇通往世界的窗。

那个年代，一份报纸就是一整天的信息量。

后来，我们有了无限滚动的信息流、永远刷不完的推荐算法、和无处不在的红点通知。信息从未如此廉价，阅读却从未如此疲惫。

**The Daily Print 想把那份仪式感还给你。**

它是一个 AI Agent Skill——告诉 AI 你关注什么，它会自动发现 RSS 订阅源、抓取每日热点、翻译整理，最终生成一份排版精美的 HTML 报纸。多栏布局、板块分区、头条高亮、名人名言，像一份真正的日报那样，每天只出一期，刚刚好。

不刷屏，不焦虑。泡杯咖啡，打开今天的报纸，这就够了。

适用于任何支持 Skill / Prompt 加载的 AI 助手（WorkBuddy、Cursor、Windsurf、Claude Code 等）。

---

## ✨ 功能特色

- **兴趣驱动** — 告诉 AI 你关注的领域，自动从 [plink.anyfeeder.com](https://plink.anyfeeder.com/) 发现匹配的 RSS 源
- **一句话生成** — 说"生成今日日报"，AI 自动抓取、筛选、翻译、排版，输出一份精美的 HTML 报纸
- **报纸级排版** — 多栏布局、板块分区、头条高亮、引言卡片，还原真实报纸的阅读体验
- **智能去重** — 自动与前一天日报比对，确保每期内容新鲜不重复
- **灵活配置** — 自定义报纸名称、内容篇幅、文章数量、输出目录
- **订阅管理** — 随时添加、删除、查看你的 RSS 订阅源

## 📦 安装

将本仓库克隆或下载到你的 AI 助手的 Skills 目录中。不同工具的路径示例：

```bash
# WorkBuddy
~/.workbuddy/skills/the-daily-print/

# Cursor
{your-project}/.cursor/skills/the-daily-print/

# 或者直接将 SKILL.md 内容作为 System Prompt / Custom Instructions 加载
```

核心文件只有三个：`SKILL.md`（主指令）、`references/template.html`（HTML 模板）、`references/style-guide.md`（排版规范）。

## 🚀 快速开始

### 首次使用

直接对 AI 说：

```
生成今日日报
```

AI 会自动进入引导流程，依次帮你完成：

1. **选择兴趣领域** — 科技、NBA、财经、游戏……按需勾选
2. **挑选 RSS 源** — AI 推荐匹配的订阅源，你来选择
3. **设置报纸名称** — 给你的日报起个名字
4. **选择内容篇幅** — 简洁版 / 标准版 / 丰富版
5. **确认输出目录** — HTML 文件保存位置

设置完成后，一份日报就生成好了！

### 日常使用

| 你说 | AI 做 |
|------|-------|
| `生成今日日报` | 抓取最新内容，生成当日 HTML 日报 |
| `添加订阅` / `我想关注 NBA` | 搜索并添加新的 RSS 源 |
| `管理订阅` / `我的订阅` | 查看当前所有活跃订阅 |
| `取消订阅 XX` | 移除指定订阅源 |
| `修改日报名称` | 更改报纸标题 |
| `调整篇幅` / `文章多一点` | 调整内容量偏好 |
| `今天不要体育板块` | 本期临时跳过指定分类 |

## 📁 目录结构

```
the-daily-print/

├── README.md                   # 本文件
├── references/
│   ├── template.html           # HTML 报纸模板
│   └── style-guide.md          # 排版规范 & CSS 类速查
└── user-config/                # 用户配置（首次运行后自动生成）
    ├── profile.json            # 报纸名称、兴趣、布局偏好
    └── subscriptions.json      # RSS 订阅源列表
```

## ⚙️ 配置说明

### profile.json

首次引导后自动生成，主要字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `newspaper_name` | 报纸名称 | `"Zach的日报"` |
| `motto` | 报头标语 | `"每日精选 · 科技前沿"` |
| `interests` | 兴趣领域 | `["科技", "NBA"]` |
| `output_dir` | 输出目录 | `"/path/to/output"` |
| `file_prefix` | 文件名前缀 | `"my-daily-print"` |
| `layout.total_articles` | 总文章数 | `"auto"` 或具体数字 |
| `layout.article_length` | 摘要篇幅 | `"short"` / `"default"` / `"long"` |
| `layout.target_pages` | 目标页数 | `2` |

### 内容量预设

| 模式 | 文章数 | 摘要长度 | 页数 |
|------|--------|---------|------|
| 📄 简洁版 | ~10 篇 | 30-60 字 | 1 页 |
| 📰 标准版（默认） | 自动 | 60-120 字 | 2 页 |
| 📖 丰富版 | ~30 篇 | 100-200 字 | 3 页 |

## 🔧 自定义 RSS 源

除了 AI 推荐的源，你也可以手动添加任意 RSS/Atom 订阅链接：

```
添加订阅 https://example.com/rss.xml
```

AI 会自动验证链接有效性，并询问分类和显示名称。

## 📄 输出示例

生成的 HTML 日报包含：

- **报头** — 报纸名称、标语、期号、日期（含农历）
- **名人名言** — 日期栏下方的英文名言
- **分板块内容** — 按订阅分类自动分区，支持多栏/列表等多种布局
- **每日引言** — 从当日新闻中提炼的启发性引言
- **页脚** — 数据来源列表

HTML 文件可直接在浏览器中打开，也适合打印。
