## 工作流

### Step 1：提取检索关键词

从用户输入或调用方传入的上下文中，提取 2-5 个检索关键词。

**关键词来源**：
- 用户描述的问题现象（如「初始化失败」、「回调丢失」）
- 涉及的技术模块（如 `ZTSDK`, `Galileo`, `WKWebView`）
- 技术栈标签（如 `iOS`, `Flutter`, `多线程`）

**同义词扩展**：自动扩展同义词以提高召回率：
- 中英对照：「伽利略」→ `Galileo`
- 缩写展开：`SDK` → `ZTSDK`, `ZTGAME`
- 相关术语：「初始化」→ `init`, `setup`, `启动`

**示例**：
- 用户描述「ZTSDK 初始化后没有回调」→ 关键词：`ZTSDK`, `初始化`, `回调`, `init`, `setup`
- 用户描述「伽利略指标数据丢失」→ 关键词：`Galileo`, `伽利略`, `数据丢失`, `指标`, `campType`

### Step 1.5：选择要检索的索引（通用 + 本项目；旧库仅显式开启）

根据 **当前工作区路径**（`Workspace Path` 或 `cwd` 最后一段目录名）与 **用户显式要求** 决定要搜哪些索引 pageId：

| 条件 | 检索范围 |
|------|----------|
| 目录名为 `KingGuard`（或用户说查 KingGuard） | 通用 `8e463063-be2a-7ae4-e91a-b2659813684e` + KingGuard `4a67d431-df3c-ba4f-21af-3c194e5015dd` |
| 路径/名称含 `camp`、`smoba`、`social-ios`、`flutter_module` 等营地工程特征（或用户说查营地） | 通用 + camp `412b3f42-6b25-7001-b71f-edb163671b3b` |
| 无法判断项目且用户未指定 | **仅**通用 `8e463063-be2a-7ae4-e91a-b2659813684e`（不猜项目库） |

**旧库**：**默认不加入**。仅当用户明确要求搜旧库 / 历史 Growth-AI-知识库 / 旧索引时，再追加 `bab47845-439d-e239-4ac7-47914da657cc`。

### Step 2：搜索索引

对 Step 1.5 中 **每一个** 选中的索引 pageId，执行以下逻辑。

**首选方式**（该份索引表格行较多时）：`document_search` 在该页内正则搜索，匹配「关键词」「别名」列：

```
document_search({
  blockId: "<当前这份索引的 pageId>",
  pattern: "ZTSDK|初始化|init|setup",
  caseSensitive: false,
  beforeBlockCount: 0,
  afterBlockCount: 0
})
```

将多个关键词（含扩展的同义词）用 `|` 拼成正则；**每个索引各调用一次**（可并行）。

**回退方式**（该份索引尚空、或 `document_search` 失败时）：

```
blocks_get({ id: "<该索引 pageId>", format: "markdown" })
```

再对正文做关键词/别名模糊匹配（规则同旧版）。

### Step 3：输出匹配结果

**如果有命中**，按相关度排序，输出时 **每条注明来源**：`【通用】` / `【camp】` / `【KingGuard】`（若检索了旧库则加 `【旧库·历史索引】`），并可再按「通用知识 / 错误经验…」分组。

**时效性提醒**：命中「版本相关」或「待验证」时照旧提示确认版本。

**如果全部索引均无命中**：
```
知识库中未找到相关记录。建议此次解决后用 knowledge-collector 沉淀（写入前先选通用或项目库）。
```

### Step 4：按需读取详情（可选）

若需读全文：用 `documents_list` 在 **命中条目所属的那棵树的根 folderId**（通用 / camp / KingGuard；若命中来自旧库则 `b448f10b-…`）下按标题查找文档，再 `blocks_get` 读取。

## 被其他技能调用时的简化输出

当由 bugfix、production-risk-checker 等技能内部调用时，输出更简洁：

```
[知识库检索] 关键词: {xxx}
→ 命中 N 条：
  ① 《文章标题》→ 结论: {摘要中最相关的结论}
  ② 《文章标题》→ 结论: {摘要}
→ 需要详情请调用 blocks_get(id: "文章pageId")
```

无命中时：
```
[知识库检索] 关键词: {xxx}
→ 无命中，继续正常流程
```

## 注意事项

- **必须执行 Step 1.5**：默认「通用 + 本项目（若能判定）」，**不得**默认搜旧库 `bab47845`；仅用户显式要求时再搜旧库
- **不要因为索引为空就跳过**：某库索引为空时，仍继续搜其他库；全部为空再输出「暂无记录」并提示用 knowledge-collector 沉淀（写入前先选库）
- **索引读取失败时不阻塞**：如果 Craft MCP 调用失败，跳过检索步骤，不影响主流程
- **避免过度读取详情**：索引中的「摘要」足够时，不需要打开文章，减少工具调用次数
- **优先使用 document_search**：比全量读取索引更高效，尤其是索引条目较多时
- **关键词扩展要克制**：扩展过多会导致噪音，保持在 5-8 个搜索词以内
