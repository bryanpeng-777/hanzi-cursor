## 灯塔看板巡检类（beacon-dashboard-inspector）

- **适用场景**：定时拉取腾讯灯塔平台业务看板数据，检测环比异常，推送企微日报
- **推荐数据源**：`beacon-data-fetcher` skill（下载导出模式，拉 2 天 CSV）
- **推荐洞察策略**：组合型 — 规则层（环比阈值，单独配置）+ AI 层（异常推断原因）
- **推荐输出渠道**：`user-wework-bot` MCP 推企微 Markdown 消息
- **脚本分工**：`analyze_metrics.py` 处理确定性部分（CSV 解析、环比计算、阈值比对），AI 只处理异常解读和措辞
- **扩展性设计**：`inspection_config.json` 多看板数组，加看板 = 追加一个 JSON 对象，零代码改动
- **认证注意**：灯塔 OA 认证 cookie 会过期，需人工扫码恢复，设计时要有降级提示（扫码后自动继续）
- **首次记录**：2026-06-11
- **最后更新**：2026-06-11
